Measured outcomes / sequential image editing

Repeated edits erase most post-hoc watermarks.

Across InstructPix2Pix, SDEdit, and FLUX.2-klein, ordinary text-guided editing sharply reduced detection of marks added after image generation. Re-embedding the decoded payload largely preserved detection.

A separate generation-time track shows a different pattern: Gaussian Shading remained detectable through InstructPix2Pix edits, while Tree-Ring did not.

02 / CORE

Post-hoc watermark retention

Detection after four consecutive edits (L4), measured against the watermarked original (L0). The same 90 source images were evaluated with each editor and watermark.

Plain editing pushed detection close to chance.

05 / CHECKS

Negative controls and interpretation

No false positives were observed on the unwatermarked tracks at the study's target operating point.

False-positive checks

Zero false positives per detector: 1,350 negative rows in stage 2, 90 in the guided test, and 450 per detector in the generated-image track.

Interpretation

Diffusion-based regeneration is destructive to many post-hoc marks. Decoding and re-embedding after an edit preserved detection more consistently than plain or guided editing.

06 / SYSTEM

System flow and mathematical definitions

The benchmark separates post-hoc marks in existing images from marks encoded during image generation.

Post-hoc watermark / sequential edit90 source images / paired prompts and seeds
1. Source + payloadChoose image x and per-image message m; fix source ID and prompt sequence.
2. Embed at L0x0 = Embed(x,m); decode to establish initial detection.
3. Edit at round rApply E(x[r-1], p[r], s[r]) for r=1...4 using IP2P, SDEdit, or FLUX.2-klein.
4. Decode + scoreMeasure matched bits, detection, fidelity, and edit alignment at L0...L4.
Generation-time watermark / separate track45 generated images / baseline edits
1. Source captionPIE-Bench++ caption conditions an SD-1.5 image generation.
2. Watermarked samplingTree-Ring or Gaussian Shading encodes the mark in initial diffusion noise.
3. Text-guided editsApply InstructPix2Pix or SDEdit sequentially.
4. Detect each levelDecode at every round and compare with the unwatermarked negative track.

Sequential image state

x[0] = Embed(x, m) x[r] = E(x[r-1], p[r], s[r]) r = 1,...,4

Image IDs, prompts, and editor seeds are paired across watermark methods.

Re-embedding control

m_hat[r] = Decode(x[r-1]) x[r] = Embed(E(x[r-1], p[r], s[r]), m_hat[r])

The ground-truth payload is not passed to the editor; decoder errors can propagate.

Detection at target FPR

X ~ Binomial(k, 1/2) detect = 1[P(X >= b) <= 10^-3]

b is the number of matching bits. k=32 for WAM/DWT-DCT-SVD and k=100 for TrustMark.

Edit success and retention

edit_success = 1[clip_dir > 0 AND clip_t_gain > 0] R[r] = (1/N) SUM_i detect(i,r)

R[r] is the detected fraction at level r. Edit quality and watermark survival are reported separately.

Watermark guidance

x_hat0 = z_t - sigma_t * epsilon_hat L_wm = BCE(D(VAE_dec(x_hat0)), m_hat) z_t <- z_t - lambda * g / RMS(g)

g = dL_wm/dx_hat0. The estimated noise is held fixed during the guidance update.

Retention decay

e(L) = (acc(L) - 0.5) / (acc(0) - 0.5) linear: e(L) = 1 - bL exponential: e(L) = exp(-qL)

One-parameter fits summarize excess bit-accuracy decay across edit levels.

Paired testsWilcoxon for continuous outcomes; McNemar for paired binary detection outcomes.
Uncertainty95% Wilson intervals for detection; percentile bootstrap over 10,000 image resamples for continuous metrics.
MultiplicityHolm correction across the editor by watermark by level family.

Guidance was tested only for WAM and TrustMark, which expose differentiable decoders. The forgery probe checks whether the same process can introduce a detectable payload on clean input.

07 / LIMITS

Limitations

These results characterize the tested watermark implementations, editors, settings, and image sets.

  • The guided-editing validation uses 18 held-out images, so intervals are wide.
  • Detection rates are not universal robustness guarantees; thresholds and edit settings matter.
  • Generation-time and post-hoc marks are different mechanisms and are reported separately.
  • Re-embedding assumes encoder and decoder access to recover and reinsert the payload.
